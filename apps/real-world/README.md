# Conduit admin (RealWorld on SurrealDB)

A back-office for the [RealWorld](https://github.com/gothinkster/realworld) "Conduit" blog,
modelled on [f1amy/laravel-realworld-example-app](https://github.com/f1amy/laravel-realworld-example-app).
There is no public API or frontend here, only the admin app, running on SurrealDB.

| Laravel table | SurrealDB table | Admin page |
|---|---|---|
| `users` | `user` | Users (verify email, set password) |
| `articles` | `article` | Articles |
| `comments` | `comment` | Comments |
| `tags` | `tag` | Tags |
| `article_tag` | `article_tag` | Article tags |
| `article_favorite` | `favorite` | Favorites |
| `author_follower` | `follow` | Follows |

Besides one page per table, **Dashboard** has stats and charts and **Feed** shows the Conduit
home feed (`GET /api/articles/feed`). Pick a reader to see articles by the authors that
user follows, or keep "Global feed". The tag picker narrows either one.

The Laravel framework tables (`password_resets`, `failed_jobs`, `personal_access_tokens`)
are not included: they are infrastructure, not Conduit data.

## Database rules (`tests/schema.surql`)

- Validation from the Laravel FormRequests: username pattern and uniqueness, email format
  and uniqueness, 8+ character passwords, title ≤ 255 and description ≤ 510 characters,
  unique slugs, one row per article/tag, article/user and author/follower pair.
- Passwords: plain text written to `user.password` is stored as a bcrypt hash. A new user
  gets the Laravel factory's default password, `password`.
- A blank article slug is derived from the title. `updated_at` is set on every change.
- The migrations' `onDelete('cascade')` is done with `DEFINE EVENT`. Deleting a user also
  deletes their articles, comments, favorites and follows. Deleting an article deletes its
  comments, favorites and tags. Deleting a tag removes it from articles.

## Set up / reset data

Vantage starts SurrealDB from `composer.yaml`. Get the host port from the Services panel
(or `docker compose -p <project> -f composer.yaml port surrealdb 8000`), then:

```bash
PORT=…
for f in tests/schema.surql tests/seed.surql; do
  curl -s -X POST "http://127.0.0.1:$PORT/sql" -u root:root -H "Accept: application/json" --data-binary @$f >/dev/null
done
tests/admin_test.sh <compose project>   # invariants: integrity, validation, hashing, cascades
```

`tests/seed.surql` is generated by `python3 tests/gen_seed.py`. It follows the Laravel
`DatabaseSeeder`: 20 users, 30 articles, 20 tags, 60 comments, plus random follows,
favorites and article tags. Loading it **replaces** all Conduit data.
